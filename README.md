# Exercícios de Programação Orientada a Objetos em C#

Projeto acadêmico desenvolvido para praticar programação orientada a objetos em C#, com quatro aplicações de console.

## 📚 Exercícios

| Pasta | Tema |
| --- | --- |
| `Ex01_Lampada` | Lâmpada |
| `Ex02_Cofre` | Cofre |
| `Ex03_Conta` | Conta |
| `Ex04_RPG` | RPG |

Cada exercício possui seu próprio projeto, com arquivos de código-fonte e um arquivo `.csproj`.

## 🛠️ Tecnologias

- C#
- .NET
- Git e GitHub

## ▶️ Como executar

Instale o .NET SDK compatível com a versão indicada no arquivo `.csproj` do exercício.

Clone o repositório:

```bash
git clone https://github.com/RicardoAmorin/afya-poo-atv01.git
cd afya-poo-atv01
```

Execute um dos exercícios:

```bash
dotnet run --project Ex01_Lampada/Ex01_Lampada.csproj
```

Para executar os demais, utilize o comando correspondente:

```bash
dotnet run --project Ex02_Cofre/Ex02_Cofre.csproj
dotnet run --project Ex03_Conta/Ex03_Conta.csproj
dotnet run --project Ex04_RPG/Ex04_RPG.csproj
```

Execute um comando por vez.

## 🎯 Objetivo

Praticar a organização de programas em classes e objetos, trabalhando com atributos, métodos e exemplos de diferentes domínios.
